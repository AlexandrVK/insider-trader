# Insider Copy Trader v0.4

Веб-сервис: берёт публичный лидерборд Hyperliquid, оценивает тайминг входов трейдеров по их истории,
следит за лучшими и копирует их согласованные входы на **виртуальном (paper) счёте** по реальным ценам.
Реальных денег и реальных ордеров в коде нет.

## Локально
    pip install -r requirements.txt
    python app.py          # http://127.0.0.1:8000  (без пароля, данные в ./data)
    python selftest.py     # офлайн-проверка логики
    python selftest.py live  # боевая проверка: хранилище (S3/локально), ИИ, Hyperliquid, Google News (ключи из .env)

## Render (Docker, Web Service)
Переменные окружения - см. `.env.example`. Обязательны `ADMIN_PASSWORD` (>= 12 символов) и `S3_*` (Backblaze B2).
Без `ADMIN_PASSWORD` на Render админка закрыта (503). UptimeRobot: HTTP(s) монитор на `https://<сервис>.onrender.com/health`, интервал 5 минут.

Локально переменные можно положить в файл `.env` рядом с кодом (см. `.env.example`).

## Отбор трейдеров (v0.4)
Запросы к Hyperliquid идут через ограничитель по весу (отдельные бюджеты для опроса позиций и для сканирования), поэтому
сканирование занимает несколько минут, но не упирается в `rate limited`. Score трейдера = нижняя граница Вилсона доли верных
решающих входов минус превышение рыночной базы над 0.5 (на растущем рынке лонги «угадывают» и без тайминга).
В аналитике `scanned_candidates` - все проверенные кандидаты с метриками (`precision`, `baseline`, `edge`) и причиной отсева (`reject`).

## Диагностика
Если при старте не удаётся подключиться к хранилищу, сервис **не падает**: `/health` отвечает, а страница управления
показывает причину с подсказками (например, несовпадение региона B2 и keyID). Кнопка «Самотест» на странице делает ту же проверку
хранилища, ИИ и внешних API, что и `python selftest.py live`.

## Веб-проверка сигнала (`ai_web`, по умолчанию включена)
Перед входом модель (AnyModel -> Groq) предлагает поисковые запросы, Python читает заголовки новостей
(Google News RSS), модель решает, отменять ли вход (до 2 раундов поиска, бюджет ~45 с, работает в отдельном потоке).
Вето засчитывается только после выполненного поиска; любая ошибка или недоступность ИИ = вход не блокируется.
Отключить: `"ai_web": false` в настройках на странице. Результаты проверки (запросы, вердикт) лежат в сигналах аналитики.

## Страница управления
Вход по паролю; пауза, обновление списка трейдеров, закрытие позиций, сброс счёта, настройки (JSON),
**«Скачать аналитику»** - файл `analytics_*.json`, его можно передать Claude для разбора и настройки параметров.
